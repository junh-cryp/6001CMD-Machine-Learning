
# 6001CMD – Machine Learning Group Project

## Project Title
Comparative Machine Learning Modelling and Ensemble Learning for Bank Marketing Subscription Prediction

## Project Overview
This project aims to predict whether a bank customer will subscribe to a term deposit using machine learning.

The project uses the Bank Marketing dataset from the UCI Machine Learning Repository.

## Dataset
- Source: UCI Machine Learning Repository
- Dataset: Bank Marketing (`bank-full.csv`)
- Total Records: 45,211
- Total Columns: 17
- Target Variable: `y`
- Problem Type: Binary Classification

Dataset source:
https://archive.ics.uci.edu/dataset/222/bank+marketing

## Machine Learning Models (Planned)
1. Logistic Regression
2. Random Forest
3. Gradient Boosting

The two best-performing models will be selected for ensemble learning.
